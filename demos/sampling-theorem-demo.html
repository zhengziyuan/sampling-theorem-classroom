奈奎斯特-香农采样定理

若连续信号的最高频率为 fmax，采样频率满足下式，则理想低通滤波可无失真重建原信号。

fs ≥ 2 fmax

当前读数

  • f0 = 120 Hz，fmax = 120 Hz。
  • fs = 400 Hz，fN = 200 Hz。
  • 采样条件成立，重建曲线与原信号基本重合。

混叠关系

当某个频率分量越过 fN，它会折回到 0 到 fN 的可见频带中，读数为 |f - kfs| 的最小值。

falias = min |f - kfs|

采样、频谱复制与重建公式

时域采样：只保留 nTs 时刻
xs(t) = x(t) · Σ δ(t - nTs)
Ts = 1 / fs = 2.500 ms，样本序列 x[n] = x(nTs)。
频域结果：原频谱按 fs 周期复制
Xs(f) = fs · Σ X(f - kfs)
相邻频谱副本间隔为 400 Hz；若副本互相重叠，就无法知道能量来自哪一个原频率。
理想低通重建：只取中心频带
H(f) = 1 / fs, |f| ≤ fN
当前 fN = 200 Hz；当 fmax ≤ fN，中心频带完整保留原信号频谱。
Sinc 插值：每个样本贡献一条 sinc 基函数
x̂(t) = Σ x[n] sinc(fs t - n)
sinc(u) = sin(πu)/(πu)。拖动 fs 时，基函数间距 Ts 会随之改变。
