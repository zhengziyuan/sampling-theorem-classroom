# 课堂使用指南

## 课前准备

下载完整项目并解压，先打开 `index.html`。准备主课件、PDF 讲义，并测试浏览器能否播放音频。

推荐使用网页演示配合普通 PPTX 授课。若计划使用 PPTM，请提前在支持 VBA 的桌面 PowerPoint 中试运行最后一页。文件信任设置由软件决定。

## 演示一：120 Hz 如何变成 30 Hz

1. 打开[采样、混叠与重建演示](../demos/sampling-theorem-demo.html)。选择单频正弦，主频保持 120 Hz，采样频率保持 400 Hz。
2. 说明 `fN = fs/2 = 200 Hz`，原频率在主 Nyquist 带内。联系时域样点与频谱副本。
3. 把采样频率降到 150 Hz。这时 `fN = 75 Hz`，120 Hz 超出边界。演示器显示的折回频率为 `|120 − 150| = 30 Hz`。
4. 切换 Sinc 和保持，区分带限重建与零阶保持。
5. 改变相位，说明采样点取决于相位。加入噪声可用于观察样本误差，但噪声和混叠是不同现象。

在 150 Hz 采样下，该正弦对应的有符号离散频率可写为 −30 Hz；页面主要显示频率位置的绝对值。解释波形时要同时考虑相位与符号。

## 演示二：同一个 B，两个采样门限

打开[sa / sa² 频谱演示](../demos/sa-spectrum-sampling-demo.html)，把 B 设为 80 Hz。

| 函数 | 本项目约定 | 频谱支撑 | 频谱副本分离的临界值 |
| --- | --- | --- | --- |
| sa(2Bt) | sa(u) = sin(πu)/(πu) | −B 到 B | fs = 2B = 160 Hz |
| sa²(2Bt) | 上述函数的平方 | −2B 到 2B | fs = 4B = 320 Hz |

先保持 `fs = 240 Hz`。sa 的矩形频谱副本分离；切换到 sa² 后，三角频谱副本会重叠。再使用低采样、临界、过采样三个按钮，观察副本边缘和相加后的观测谱。

这里 B 是公式的频谱尺度参数。sa² 的最高频率是 2B，不能把参数 B 直接当成两个信号共同的最高频率。

## 演示三：听带宽损失和混叠

打开[音频试听页](../demos/audio-sampling-demo.html)，依次播放五种采样率处理版本。观察高频细节和明亮感的变化，再比较有滤波和无滤波的 8 kHz 版本。

所有 WAV 都以 44.1 kHz 播放，每段约 10.5 秒。音频生成工具先在 44.1 kHz 参考信号上处理，滤波版本使用约 `0.46 × 目标采样率` 的低通截止，再进行线性重采样和回到播放采样率。播放文件的采样率与演示标签的含义应分开说明。

程序对片段做了归一化。因此响度变化不适合作为本实验的主要判断依据。重点观察频带、高频细节以及无抗混叠版本中的折回成分。

## 图片演示

打开[图片采样扩展课件](../materials/slides/采样定理_图片采样Demo_扩展版.pptx)。前 4 页为时域与频谱截图，第 5–9 页为二维图像采样。先比较原图与稀疏网格，再比较直接采样和预滤波后采样。

## 教学边界

原课件保留了常见的 `fs ≥ 2B` 表述。讲到等号时，应说明频谱边界条件和信号类别。尤其不能把它当成所有纯正弦都能恢复的无条件保证：`sin(2πBt)` 在 `t=n/(2B)` 处全为零。

网页演示使用有限时间窗口和有限 Sinc 支撑。即使处于过采样状态，数值重建也可能有小误差；图中的 RMSE 不等同于对无限长度采样定理的证明。频谱图用于解释复制、支撑与折回关系。

原始课件中的截图是预设状态，现场交互请打开网页或使用支持 VBA 的 PPTM。

## 结束时的小测

- 为什么采样前要进行抗混叠滤波？
- 用 150 Hz 采样率记录 120 Hz 正弦，频率绝对值折回到多少？
- 为什么 sa²(2Bt) 的采样门限比 sa(2Bt) 更高？
- 实际录音系统为何通常高于理论最低采样率？

参考回答分别为：避免高频折回到目标频带、30 Hz、平方后频谱支撑扩展到 ±2B、给滤波器过渡带与实际信号留余量。
